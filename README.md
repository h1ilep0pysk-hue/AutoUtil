AutoUtil

Утилита для Windows, которая живёт в системном трее и делает две вещи: распознаёт текст с экрана и наводит порядок в папке «Загрузки».

Возможности

Захват текста. Нажмите Ctrl+Shift+O, выделите область экрана, и распознанный текст окажется в буфере обмена. Последние захваты доступны в трее и в окне приложения.

Сортировка файлов. AutoUtil следит за выбранными папками и переносит новые файлы по правилам: чеки, фото из поездок, документы, установщики. Файлы никогда не удаляются, каждое перемещение записывается в журнал и может быть возвращено одной кнопкой.

Безопасный старт. В первую неделю можно включить режим «только план»: утилита покажет, что бы переместила, но ничего не тронет.

Требования
Windows 10 или 11
Python 3.12
Около 1 ГБ свободного места для зависимостей (PySide6, OCR-модели)
Установка
git clone <адрес репозитория> autoutil
cd autoutil
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
python tools/make_icons.py
Запуск
python main.py

При первом запуске откроется мастер: папка для отслеживания, горячая клавиша и автозапуск. После него иконка появится в трее.

Управление:

двойной клик по иконке в трее открывает окно приложения;
правый клик открывает меню: пауза, «не беспокоить», последние захваты, журнал, настройки, выход.
Настройка

Все параметры доступны в разделе «Настройки» окна приложения:

тема (серая тёмная или светлая), размер шрифта, компактные списки;
раздел, который открывается первым;
горячая клавиша захвата (применяется после перезапуска);
режим «только план», папки-исключения, автозапуск.

Правила сортировки включаются и выключаются в разделе «Правила».

Где хранятся данные

Всё в %APPDATA%\AutoUtil\:

Файл	Назначение
settings.toml	основные настройки
prefs.toml	внешний вид и поведение окна
rules.json	правила сортировки
journal.jsonl	журнал перемещений
history.jsonl	последние захваты текста
learned.json	привычки для подсказок сортировки
logs\autoutil.log	технический лог

Папка программы не изменяется.

Тесты
pytest -q
Сборка exe
pip install pyinstaller
pyinstaller build/autoutil.spec

Результат появится в dist\AutoUtil.exe.

Ограничения MVP
Работает только на Windows.
Хоткей и автозапуск меняются после перезапуска.
OCR работает офлайн, но первый захват занимает несколько секунд, пока загружается модель.
Классификация по тексту зависит от качества распознавания; для сканов правила по тексту лучше отключить.
Exe не подписан, антивирус может показать предупреждение.
Автообновления нет.
